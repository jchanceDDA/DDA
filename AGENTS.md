# Repository Agent Instructions

For this repository, follow this workflow on every user-requested change:

1. Execute requested code/content changes immediately.
2. After making changes, rebuild the Jekyll site (`bundle exec jekyll build`).
3. When applicable, provide the local page URL (this repo uses port `4001` unless the user specifies otherwise).
4. Do not claim work is complete until commands have actually been executed.
5. Do not commit or push unless the user explicitly requests it.
